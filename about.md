# Smart Snap

Snaps dragged objects to nearby object edges and centers in the editor,
similar to the smart guides in design tools like Figma or Illustrator.

## Features

- Snaps to the edges and centers of nearby objects, not just the grid
- Configurable snap distance
- Optional guide lines shown while snapping
- Hold a key to temporarily disable snapping for precise placement

## Settings

| Setting | Description |
|---|---|
| Enable Smart Snap | Master on/off toggle |
| Snap Distance | How close an edge needs to be before it snaps |
| Snap to Centers | Also snap to horizontal/vertical centers, not just edges |
| Show Guide Lines | Draw a line when a snap is active |
| Disable-While-Held Key | Hold this key while dragging to bypass snapping |
